# yakuza-kiwami-thai-mod

แปลไทย Yakuza Kiwami (2025 Remaster) — Thai fan-translation mod

โหลดตัวล่าสุดได้ที่หน้า [Releases](../../releases/latest) · วิธีติดตั้งและคำถามที่พบบ่อยอยู่ที่ [yakuzathai.com/game/kiwami/](https://yakuzathai.com/game/kiwami/)

> สำหรับฉบับปี 2025 บน Steam (โฟลเดอร์เกมชื่อ `Yakuza Kiwami R`) เท่านั้น

## ม็อดนี้แปลอะไรบ้าง

เนื้อเรื่องหลักและคัตซีนทุกบท เควสเสริม มินิเกม บทสนทนาข้างถนน เมนู ไอเทม ร้านค้า ถ้วยรางวัล และเครดิต
พร้อมฟอนต์ไทยที่ฝังมาในตัว หน้าไตเติล การ์ดแนะนำตัวละคร และหน้าชื่อบทเป็นภาษาไทย

## วิธีติดตั้ง

ม็อดเป็นแบบ "วางทับ" (drop-in) ไม่ต้องใช้ Shin Ryu Mod Manager

1. โหลดไฟล์ zip จากหน้า Releases แล้วแตกไฟล์ จะเห็นโฟลเดอร์ `runtime`
2. เปิดโฟลเดอร์เกม (Steam → คลิกขวาที่เกม → Manage → Browse local files)
3. **สำรองไฟล์เดิมก่อน** — ก๊อปโฟลเดอร์ `runtime` เดิมของเกมเก็บไว้
4. ปิดเกมให้สนิท แล้วลากโฟลเดอร์ `runtime` จากม็อดไปวางทับในโฟลเดอร์เกม แล้วตอบ Replace
5. เข้าเกม ข้อความเป็นภาษาไทยทันที

ถ้าเคยลงม็อดเวอร์ชันก่อน วางไฟล์เวอร์ชันใหม่ทับได้เลย

## ตัวเสริมสระ/วรรณยุกต์ซ้อน

ในชุดม็อดมี `dinput8.dll` + `kr_thai_narrow.asi` + `kr_thai_narrow.ini` (ใน `runtime\media\`) ทำให้สระบนล่างซ้อนกับพยัญชนะ
และจัดระยะตัวอักษรตามความกว้างจริง แพตช์เฉพาะในหน่วยความจำตอนเกมรัน ไม่แก้ไฟล์ exe ตัวเสริมนี้ไม่บังคับ

- ปิดชั่วคราว: แก้ `kr_thai_narrow.ini` เป็น `Enabled=0`
- ระยะห่างตัวอักษรดูแปลก: แก้เป็น `Proportional=0`
- ปิดถาวร: ลบ `dinput8.dll` ออกจาก `runtime\media\`

## ถอนม็อด

เอาโฟลเดอร์ `runtime` ที่สำรองไว้วางทับกลับ หรือให้ Steam ตรวจสอบความสมบูรณ์ของไฟล์ (Properties → Installed Files →
Verify integrity) แล้วลบ `dinput8.dll`, `kr_thai_narrow.asi`, `kr_thai_narrow.ini` ใน `runtime\media\` เอง

## หมายเหตุ

- ส่วนที่ยังเป็นภาษาอังกฤษ (ฝังอยู่ในตัวเกม .exe หรือในรูปภาพ): หัวข้อเมนูหยุดเกมบางส่วน หัวตาราง Completion List
  Play Time/Difficulty ปุ่มแถบล่าง (Pause Menu/Map/Back) ป้ายแผนที่ (Eatery/Store/...) และตัวหนังสือบนภาพช่วงเปิดเรื่องบางภาพ
- Steam อัปเดตเกมหรือกด Verify จะเขียนไฟล์กลับเป็นต้นฉบับ ต้องวางม็อดทับใหม่
